## 修正

- 手续费从有效成交价格中移出，按实际成交金额单独收取一次；买入金额包含最低手续费并受可用现金约束。
- 已完成交易日的信号在下一条日线开盘成交；ATR仓位计算只使用上一条已完成日线。最后一条日线的新信号不成交。
- 样本末仍持仓时，以最后收盘价结算，记录 `end_of_sample`；这属于研究结算假设。
- 回测 RSI 与技术分析接口统一使用 `ta.momentum.RSIIndicator` 的 Wilder 平滑和预热规则。
- 平仓收益包含买卖两侧手续费；最大回撤和夏普比率按策略账户每日净值计算，不再直接使用标的价格收益。
- 零成本对照沿用相同仓位规则，避免把仓位差异误认为成本影响。
- 修复既有回测测试的数据替换位置，使其使用模拟行情，避免意外访问真实网络；透传行情源错误信息。
